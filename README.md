# SMP Negeri 25 Purworejo — Website Ekstrakurikuler

Website pameran pendidikan dan daftar ekstrakurikuler SMP Negeri 25 Purworejo.

## Isi pembaruan
- Daftar lengkap **18 ekstrakurikuler**.
- 3 bidang: **Olahraga (7), Seni (7), Wawasan Kebangsaan (4)**.
- Filter bidang interaktif.
- Dokumentasi foto olahraga dan Pramuka yang sudah tersedia di folder `assets`.
- Galeri foto dengan fitur perbesar (lightbox).
- **Poster pameran dan poster web tidak dimasukkan ke website**, sesuai permintaan.
- Tampilan responsif untuk komputer dan HP.

## Struktur
- `index.html` — halaman utama.
- `styles.css` — desain dan responsif.
- `script.js` — filter, menu mobile, dan galeri.
- `assets/` — logo dan foto kegiatan.
